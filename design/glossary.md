# Glossary

> **Status:** Current
> **Last updated:** 2026-11-18
> **See also:** [README](README)

Terms used across the SekkOS design docs, with pointers to the doc that explains
them in context.

## General

| Term | Meaning |
| --- | --- |
| **SekkOS** | The NixOS-based operating system described here. |
| **SekkOS Settings** | The planned GUI frontend for configuring the system without writing Nix. See [`user-experience`](user-experience). |
| **Live image / ISO** | Bootable installer medium with a Plasma 6 live session. |
| **Source of truth** | These design docs; code changes must keep them in sync. See [`README`](README). |

## Nix and NixOS

| Term | Meaning |
| --- | --- |
| **Nix** | The functional package manager and language underpinning SekkOS. |
| **NixOS** | A Linux distribution configured declaratively through Nix modules. |
| **Flake** | A versioned, hermetic project input/output description with declared inputs. |
| **`flake.lock`** | Lock file pinning exact input revisions and hashes; committed on installed systems. |
| **Generation** | An immutable system version created by `nixos-rebuild`, with its own boot entry. |
| **Nix store** | `/nix/store`, read-only content-addressed storage for packages and system closures. |
| **Garbage collection** | Removal of unreferenced store paths and old generations, bounded by retention policy. |
| **Module** | A NixOS configuration unit declaring options and implementing behaviour. |
| **Atomic upgrade** | Building a complete new generation and switching to it in one step; failures leave the old one intact. |
| **Rollback** | Returning to a previous generation from the boot menu or SekkOS Settings. |
| **Unfree software** | Packages with non-free licences; opt-in in SekkOS. |
| **Calamares** | The graphical installer currently used by the live ISO. |
| **Icicle** | An alternative installer from Snowfall; under evaluation, not adopted. |

## Security

| Term | Meaning |
| --- | --- |
| **LUKS** | Linux Unified Key Setup; disk encryption format used for full-disk encryption. |
| **Recovery key** | A separately stored key that can unlock encrypted data if the password is lost. |
| **TPM2** | Trusted Platform Module; can hold secrets and enable measured/transparent unlock. |
| **Secure Boot** | Firmware feature that verifies boot components against trusted keys. |
| **Sandboxing** | Restricting an app's access to files, devices, network and privileges. |
| **Portal** | A mediated interface (e.g. file chooser) that grants specific access instead of blanket access. |
| **Polkit** | Framework for granting administrative actions to unprivileged users with authentication. |
| **Firewall** | Stateful host firewall; enabled by default in the pinned nixpkgs. |
| **Threat model** | The assets, adversaries and mitigations in [`threat-model`](threat-model). |
| **Secure by default** | Security is on out of the box, with explicit, labelled escape hatches. |

## Identity and cryptography

| Term | Meaning |
| --- | --- |
| **DuckPAM** | SekkOS's PAM module that unlocks a post-quantum identity with the login password. See [`duckpam`](duckpam). |
| **Duckling** | A configured command pair that receives a decapsulated secret at login. |
| **NTRU** | A lattice-based post-quantum public-key cryptosystem; SekkOS uses NTRU-HPS-2048-509. |
| **KEM** | Key Encapsulation Mechanism; used to establish shared secrets. |
| **Argon2** | Password-based key derivation function used to derive the key that encrypts the private key. |
| **AES-256-GCM** | Authenticated symmetric encryption used for the stored private key. |
| **Root identity** | The DuckPAM public key that identifies a user across SekkOS services. |
| **Fingerprint / safety number** | Human-checkable representation of a public key. |
| **`duckshadow`** | `/etc/duckshadow`, the encrypted key store. |
| **`ducklings`** | `/etc/ducklings`, the configuration of duckling commands. |
| **Recovery codes** | Single-use codes generated by default for identity recovery. |
| **Trusted contacts** | Opt-in threshold recovery using other people from the user's groups. |

## Networking and sharing

| Term | Meaning |
| --- | --- |
| **DuckNet** | SekkOS's relationship-based networking layer built on Netmaker and WireGuard. See [`ducknet`](ducknet). |
| **WireGuard** | A modern VPN protocol providing encrypted point-to-point tunnels. |
| **Netmaker** | Software used to manage WireGuard meshes; self-hosted by the user or group. |
| **Controller** | The Netmaker control plane; distributes configuration, not content. |
| **Peer** | A device or service participating in a group's WireGuard mesh. |
| **Relay** | Optional fallback for peers that cannot connect directly. |
| **Kill switch** | Option that blocks traffic outside the encrypted mesh. |
| **Iroh** | Peer-to-peer content distribution and replication library used for file sharing. |
| **Pinning** | Promising to retain a copy of a shared file; the UI shows independent copy counts. |
| **Ticket / capability** | A time-limited token granting access to a specific share. |
| **End-to-end encryption** | Only communicating parties can decrypt content; servers and relays cannot. |
| **Group** | A first-class Contacts entity that owns network, file and app policies. |
